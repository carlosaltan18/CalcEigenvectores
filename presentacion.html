03 · Calculadora espectral

Eigenvalores y eigenvectores

Un eigenvector conserva su dirección cuando la matriz lo transforma. El eigenvalor indica cuánto se estira, contrae o invierte.

A · v = λ · v

La aplicación resuelve el polinomio característico:

det(A − λI) = 0

Ejemplo de matriz

410130002

La app calcula determinante, traza, rango, eigenvalores, eigenvectores y diagonalización.

04 · Interpretación automática

La matriz también cuenta una historia geométrica

det(A)Cambio de área o volumen
tr(A)Suma de eigenvalores
rangoDimensiones conservadas
λDirecciones principales

Determinante

Si |det(A)| = 0.40, la matriz reduce el área al 40%. Si vale 0, aplasta una dimensión.

Simetría

Una matriz simétrica tiene eigenvectores ortogonales, útiles para interpretar datos y PCA.

Diagonalización

Indica si la transformación puede expresarse mediante escalamiento en direcciones independientes.

05 · Laboratorio PCA

PCA encuentra las direcciones con mayor información

El análisis de componentes principales reduce un conjunto de muchas variables a unas pocas componentes que conservan la mayor parte de la variación.

  • Acepta datasets de ejemplo, datos pegados o archivos CSV.
  • Permite estandarizar variables con unidades diferentes.
  • Proyecta los datos en 2D o 3D.

06 · Proceso PCA

Qué ocurre dentro del PCA, paso a paso

No elimina variables al azar: encuentra nuevos ejes que resumen mejor el comportamiento de los datos.

01

Organizar

Las filas son observaciones y las columnas son variables: por ejemplo, edad, peso y calificación.

02

Centrar

Se resta la media de cada columna. Así el análisis se enfoca en las diferencias y no en el tamaño absoluto.

03

Covarianza

La matriz de covarianza mide qué variables cambian juntas y revela la forma de la nube de puntos.

04

Nuevos ejes

Se calculan eigenvectores. Cada uno marca una dirección principal de variación; su eigenvalor indica importancia.

05

Proyectar

Se conservan los k ejes más importantes y se proyectan los datos. Menos dimensiones, mismos patrones esenciales.

Lectura rápida: componentes con eigenvalores grandes explican más varianza; elegir k es elegir cuánta información se desea conservar.

07 · PCA para imágenes RGB

Cómo se comprime una imagen sin eliminar todo el detalle

Una imagen a color se separa en tres matrices de píxeles: rojo, verde y azul.

RGB

Cada canal se procesa por separado para conservar la información de color.

Xcentrado = X − media

C = cov(Xcentrado)

Z = Xcentrado · Vk

X̂ = Z · Vkᵀ + media

08 · PCA vs. SVD

Dos métodos para aproximar una imagen con menos información

PCA por canal RGB

Centra cada canal de color y encuentra los eigenvectores con mayor varianza.

Ventaja: permite interpretar cuánta varianza explica cada componente.

Reconstrucción: conserva k componentes y recupera la media.

SVD de rango k

Descompone cada matriz de color en tres matrices:

A = UΣVᵀ

Conserva los k valores singulares más importantes para reconstruir una aproximación compacta.

La aplicación compara ambos resultados con la misma imagen y el mismo valor de k.

10 · Aplicaciones

Álgebra lineal detrás de tecnologías cotidianas

1901 · PCA

La estadística comienza a resumir datos complejos mediante componentes principales.

1960–1980 · SVD

La descomposición matricial se vuelve importante para cálculo numérico, señales y compresión.

1991 · Eigenfaces

PCA ayuda a representar rostros usando menos características.

Recomendadores

Las matrices usuario-producto ayudan a sugerir películas, música y compras.

Actualidad

Visión por computadora, videojuegos, IA, análisis científico y compresión.

11 · Demostración y conclusión

La demostración en vivo

  1. Ingresar una matriz y observar sus eigenvalores.
  2. Cargar un CSV y reducirlo a dos o tres componentes.
  3. Subir una imagen RGB y cambiar el valor de k.
  4. Comparar la reconstrucción PCA con SVD.

Conclusión

El proyecto convierte conceptos de álgebra lineal en herramientas visibles y aplicables.

Eigenvalores explican direcciones especiales. PCA conserva los patrones principales. SVD crea aproximaciones compactas.
